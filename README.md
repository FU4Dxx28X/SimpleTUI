# SimpleTUI
ini cuman library tui C++ yang dibangun diatas C++
itupun belum selesai semua, ini hanya beberapa
jadi, kalo mau ngembangin lagi silahkan aja

## clone (termux)
```
pkg update && pkg upgrade -y
pkg i clang make cmake git ncurses -y
git clone https://github.com/FU4Dxx28X/SimpleTUI.git
cd SimpleTUI
cmake -B build && cmake --build build -j4
./run
```
